## ✨ Features

- 🎨 **Glassmorphism Design** - Modern frosted glass effects
- 🌈 **Animated Gradients** - Cyan → Purple → Pink color flows
- 🖱️ **Custom Cursor** - Interactive cursor with glow effects (desktop)
- ✨ **Particle Background** - 50 floating animated particles
- 📜 **Scroll Animations** - Smooth fade-in effects
- 🎭 **3D Hover Effects** - Interactive card transformations
- ⌨️ **Typing Animation** - Auto-rotating role descriptions
- 📱 **Fully Responsive** - Optimized for all devices
- 🚀 **Performance Optimized** - 60fps smooth animations
- ♿ **Accessible** - Semantic HTML, keyboard navigation

## 🚀 Quick Start

### Prerequisites

- Node.js installed
- Basic knowledge of HTML/CSS

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Customization

1. **Update Personal Info**

   - Edit name, bio, contact details in `index.html`
   - Update social media links
   - Replace CV file

2. **Add Your Projects**

   - Edit `index.js` to modify projects
   - Add project images to `/assets/`

3. **Deploy**
   - Build: `npx tailwindcss -i ./src/input.css -o ./dist/output.css --minify`
   - Deploy to Netlify, Vercel, or GitHub Pages
