## 🎨 Design System

### Color Palette:

```
Primary: #06b6d4 (Cyan)
Secondary: #8b5cf6 (Purple)
Accent: #ec4899 (Pink)

Background: #0a0a0a (Black)
Cards: rgba(255,255,255,0.03)
Text: #f9fafb (White)
Muted: #9ca3af (Gray)
```

### Typography:

- **Headings:** Space Grotesk (Modern, Geometric)
- **Body:** Inter (Clean, Readable)

### Spacing:

- Sections: 80px (py-20)
- Cards: 32px padding (p-8)
- Grid gaps: 32px (gap-8)

---

## 📱 Responsive Breakpoints

- **Mobile:** < 768px

  - Single column layouts
  - Stacked navigation
  - Larger touch targets
  - Disabled custom cursor

- **Tablet:** 768px - 1024px

  - 2-column grids
  - Optimized spacing
  - Hybrid navigation

- **Desktop:** > 1024px
  - 3-column grids
  - Full animations
  - Custom cursor active

## ⚡ Performance

- **CSS:** Utility-first with Tailwind (minimal overhead)
- **JavaScript:** Alpine.js (15KB) + vanilla JS
- **Animations:** Hardware-accelerated CSS transforms
- **Images:** Lazy loading with fade-in
- **Total JS:** < 50KB (excluding Alpine CDN)
